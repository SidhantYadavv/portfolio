# OG image fonts

Static font files for the generated social preview image (src/app/og-card.tsx).
The OG renderer only accepts ttf/otf/woff, so these are separate from the site's woff2 fonts.

- Big Shoulders (ExtraBold, 72pt optical size) and Schibsted Grotesk (Regular): Google Fonts, SIL OFL 1.1
- Departure Mono: Helena Zhang, SIL OFL 1.1 (see src/fonts/DepartureMono-LICENSE.txt)
